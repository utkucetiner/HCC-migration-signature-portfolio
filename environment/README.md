# Computational environment

Use Python 3.11. Install `requirements-lock.txt` for the tested package snapshot; direct dependencies are listed in `requirements.txt`. Installation was independently tested on macOS arm64. This is not a cross-platform lock.

R 4.4.1, inferCNV 1.22.0 and JAGS 4.3.2 describe the original CNV environment. A complete R dependency lock and a clean R/inferCNV/JAGS rebuild are still missing. See [execution and validation scope](../docs/REPRODUCING.md).
